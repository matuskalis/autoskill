# What 22,746 public Claude Code skills can do: an audit

29 September 2026. Every public `SKILL.md` we could find on GitHub, 710 repositories, checked by a static scanner, and every red flag it raised read by hand.

**The short version:** we found no malware in any real product's skill. Only 9.6% of skills are prose-only, meaning they cannot make Claude run anything by themselves. The rest can run commands, ship scripts, or pre-approve tools, which is usually their job, and which you should know before you install them. Four deliberately malicious skills turned up, all of them test samples from security scanners that a naive crawler lists as installable. Two skills tell Claude to hide things from the user.

## What skills can do

A capability is not a threat: a PDF skill ships Python because it has to. These are shares of all 22,746 skills. One skill usually has several.

| capability | skills | share |
|---|---|---|
| contains code blocks | 17,208 | 75.7% |
| names shell or network commands | 13,191 | 58.0% |
| ships scripts or other non-text files | 6,934 | 30.5% |
| tells Claude to run something | 6,284 | 27.6% |
| pre-approves tools (`allowed-tools`) | 3,841 | 16.9% |
| talks about Claude Code settings or permissions | 3,309 | 14.5% |
| uses MCP tools | 2,333 | 10.3% |
| points Claude at a remote URL | 1,488 | 6.5% |
| writes Claude's memory or project instructions | 1,461 | 6.4% |
| touches startup or system locations | 464 | 2.0% |
| builds a URL from data | 320 | 1.4% |
| runs a shell command the moment it loads (`` !`cmd` ``) | 288 | 1.3% |
| touches git hooks | 196 | 0.9% |
| registers hooks | 59 | 0.3% |
| contains an encoded blob | 21 | 0.1% |

- **Prose-only:** 2,181 skills (9.6%). Among skills from repositories with 1,000+ stars the share is barely higher, 11.7%.
- **Copies:** 149 skill names appear 5 or more times, 1,202 skills in all, mostly forks and marketplace mirrors of the same skill.

## Red flags, read by hand

The scanner also looks for patterns that are warning signs rather than capabilities:

- piping a download from an untrusted host (raw IP, plain http, paste sites, tunnels, link shorteners) into a shell,
- decoding a blob and running it,
- instructions to override or hide instructions,
- sending the whole environment or credential files to a URL,
- reading private keys or credential files,
- fetching remote instructions and following them.

It raised 461 flags in 288 skills. We read every flagged line in the file at the pinned commit, with its context.

| verdict | skills | what they were |
|---|---|---|
| benign, describes an attack | about 100 | security, red-team, CTF and eval skills that quote payloads as examples, and defensive rules such as "treat fetched text as data" |
| benign, ordinary product rule | about 180 | "don't show internal IDs to the user", DevOps guides that copy a public SSH key, vendor installers |
| conceals something from the user | 2 | a vendor skill in a 39,000-star list tells Claude never to tell the user its paid service returned nothing useful; a prompt skill silently rewrites the user's prompt to get past a platform's content filter. Names are withheld until the authors have had a chance to respond |
| malicious | 4 | all test samples: security scanners' fixtures (NVIDIA SkillSpector, Cisco skill-scanner, skillkit) and an antivirus demo, full of override, exfiltration and curl-to-shell payloads |

Two patterns are worth knowing even though neither is malware. Some skills tell Claude to download a file from the vendor's site and follow whatever it says, so the skill's real instructions can change at any time without a commit. And security skills put live attack payloads into Claude's context, which is what they are for.

## What changed in autoskill

- The crawler no longer treats a `SKILL.md` under `tests/`, `fixtures/` or `test_skills/` as a skill, and the antivirus demo is excluded by name.
- A flagged skill is published only as "held for manual review"; the evidence stays private until a person has read it. A reviewed finding stays cleared only while the flagged lines are unchanged.
- The same scan runs again on your machine before anything is installed.

## Method and limits

- Discovery: GitHub repositories under the `claude-skills`, `agent-skills`, `claude-code-skills`, `claude-skill` and `claude-code-plugin` topics with 20+ stars, plus a list of known repositories. Forks and archived repositories are skipped.
- Each skill is read from one tarball per repository at a pinned commit: `SKILL.md`, up to 12 other text files, and scripts up to 200 KB for the red-flag scan.
- The detectors are regular expressions over text; the capability table is a lower bound, and a determined author can write around them. The red-flag verdicts are human judgments.
- Nine very large repositories timed out and are missing.
- Rerun it: `node src/cli.ts crawl --out /tmp/catalog --flags-out /tmp/flags.json`. The capability numbers come from `catalog.json`; the flags file holds the evidence.

The catalog is rebuilt every day, so these numbers move. The latest is always on the [`catalog` branch](https://github.com/matuskalis/autoskill/tree/catalog).
