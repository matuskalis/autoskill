# Session report, 29 Sep 2026

Two-hour autonomous session on Opus 5.5 with subagents. Plan: `docs/SESSION-PLAN.md`.

## Shipped

- **`autoskill eval`**: measures a skill's uplift with `claude plugin eval`. Tasks come from the skill's name and description only; one llm grader per check; a with-only Skill-fired indicator; paired scoring per case; `partial`, `ceiling`, focused delta over checks that separated the arms. `--hard` for tasks at the edge of the model's ability, `--workspace` for file-editing tasks (safe-tier only, Write and Edit, never Bash).
- **Eval safety**: a skill whose frontmatter pre-approves tools, registers hooks or runs shell on load is never loaded; the staged folder keeps only SKILL.md and text references, so no hooks, agents, commands, `.mcp.json` or manifest can load as plugin parts. Found live: `value-at-risk-calculator` pre-approves Bash; its run was stopped before scoring.
- **Hook**: MIN_SCORE 9 to 15 and canonical-skill ranking (copy bonus, generic-name penalty), both chosen on a 156-prompt labelled benchmark (`scripts/bench-hook.ts`) and kept only if F1 improved on both halves. Benchmark F1 0.560 to 0.666, silent-prompt fire rate 16.7% to 8.3%; real prompts 8% to 5%.
- **Measured ranking**: a measurement lifts a skill up to 30% or drops a harmful one, only for the measured commit, when the skill loaded in at least half the runs, the run finished, and the task left headroom.
- **Classifier**: flags MCP tool use, git hooks, Claude memory or CLAUDE.md writes, startup paths, remote-URL instructions, data-in-URL and encoded blobs; license paragraphs no longer count as code.

## Findings

- 23 popular skills, 30 runs on Opus 5.5: almost every result is at the ceiling (no-skill score 0.9 or more). The largest gain, +0.11, is from a skill that loaded in only a third of runs; several skills made answers slightly worse. Harder generated tasks did not escape the ceiling.
- This matches the literature (`docs/research-skill-uplift.md`): public skills add little on knowledge a frontier model already has; gains come from procedures, checklists, tools and knowledge the model lacks.
- Evaluation cost on the plan: about $5 to $12 API-equivalent per skill at 3 tasks x 2 runs x 2 arms with an Opus judge.
